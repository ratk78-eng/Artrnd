    Пакетная обработка чертежей
    Выберите сразу несколько чертежей. Каждый распознаётся без модели ИИ, строится в КОМПАСе, сверяется с массой из штампа и проверяется на ошибки КОМПАСа. Чертежи, которым нужна модель ИИ, помечаются — их разберите по одному.
    ЧертёжСостояниеРаспознано какМасса моделиПо штампуОшибки КОМПАСа
    Настройки
    Нужна модель, которая понимает изображения и быстро отвечает: рассуждающие модели читают чертёж очень долго. «Как основная» — использовать модель выше.
    точносвободно
    Насколько свободно модель выбирает ответ. Ближе к нулю — строже и предсказуемее, это лучше для построений по размерам. Ближе к единице — разнообразнее, но чаще ошибки. Рекомендуется 0,1–0,3.
