NEST DESKTOP — PDF REPORT PATCH

Это дополнение для настольной версии NEST_DESKTOP_rebuilt_v3 (после CAD_rev4). Оно не заменяет полный проект.

1. Закройте NEST.
2. Скопируйте add_pdf.py и pdf_report.py ИЗ ЭТОГО АРХИВА в свою папку NEST_DESKTOP рядом с main.py и cad.py (не распаковывайте поверх main.py).
3. Откройте cmd в папке NEST_DESKTOP. Установите: C:\Python\python.exe -m pip install --user reportlab
4. Примените: C:\Python\python.exe add_pdf.py
5. Запустите NEST как обычно. После расчёта станет доступна кнопка «Отчёт PDF»; выберите место для сохранения.

Патч проверяет точные участки main.py и отказывается от изменений, если версия отличается. Сохраняет резервную копию main.py.before_pdf. Повторно его не применяйте. Файл pdf_report.py должен остаться рядом с main.py. PDF содержит параметры, итоги и состав каждого хлыста с кириллическими именами; шрифт Arial/Segoe UI берётся из Windows. PDF-отчёт не зависит от успешного STEP-экспорта.

Проверено: Python-синтаксис, вставка кнопки на тестовой модели исходника и генерация непустого PDF с кириллицей (тестовый шрифт Linux). Не проверено: запуск кнопки в пользовательской версии Windows. Если патч сообщает «версия main.py отличается», пришлите файл main.py, не меняйте его вручную.
