# lathe_cam: токарный CAM для KMT-KE со стойкой SINUMERIK 808D

Прототип. Читает задание в JSON (заготовка, контур детали, инструмент, операции), строит траектории и выдаёт программу для SINUMERIK 808D ADVANCED T: основную программу `.MPF`, подпрограмму контура `.SPF` и эскиз `.svg` для проверки на экране.

## Файлы

| Файл | Назначение |
|---|---|
| `machine.py` | Параметры станка KMT-KE (диаметр, РМЦ, обороты, позиции резцедержки, точка смены инструмента) |
| `contour.py` | Контур детали: отрезки и дуги в плоскости XZ, X в диаметре |
| `cam.py` | Задание и операции: торцовка, черновая/чистовая/полная обработка по контуру, канавка, резьба, сверление по оси, отрезка |
| `post_808d.py` | Постпроцессор 808D |
| `preview.py` | SVG-эскиз: заготовка, контур, перемещения |
| `__main__.py` | Запуск из командной строки |
| `examples/val.json` | Пример: вал Ø60×110 |
| `test_lathe_cam.py` | Тесты |

CAM и постпроцессор разделены: `cam.py` выдаёт нейтральный список перемещений и вызовов циклов, а `post_808d.py` переводит его в кадры 808D. Для другой стойки достаточно написать ещё один постпроцессор.

## Запуск

Нужен Python 3.11+, сторонние библиотеки не нужны. Из корня репозитория:

```
python -m lathe_cam lathe_cam/examples/val.json -o exports
```

Ключи: `-m machine.json` (свои параметры станка, только изменяемые поля), `--labels` (контур в той же программе по меткам, без `.SPF`), `--vrt` (добавить `_VRT` в циклы), `-n` (номера кадров N10, N20...).

Программы пишутся в ASCII с переводами строк CRLF; русские комментарии транслитерируются, потому что не каждая стойка читает кириллицу с USB.

## Задание

- `stock`: `diameter`, `length`, `face_allowance` (припуск на торце, Z0 будет на чистом торце).
- `contour`: `name`, `start` и `elements`. Элемент `{"x":..,"z":..}` это отрезок, `{"type":"arc","x":..,"z":..,"r":..,"dir":"cw"|"ccw"}` это дуга (G2/G3 с CR=). Направление дуги считается при взгляде с Z вправо и X вверх. Контур идёт от торца к патрону и последним элементом выходит за заготовку.
- `tools`: номер позиции → `name`, `d` (корректор, по умолчанию 1), `nose_radius`.
- `operations`, по порядку:

| type | Что делает | Основные параметры |
|---|---|---|
| `face` | Торцовка проходами G1 до центра | `feed`, `depth` |
| `rough` | Черновая по контуру, CYCLE95 VARI=1 | `feed`, `depth`, `allowance_x`, `allowance_z` |
| `finish` | Чистовая по контуру, CYCLE95 VARI=5 | `feed` |
| `complete` | Черновая + чистовая, CYCLE95 VARI=9 | `feed`, `depth`, `finish_feed` |
| `groove` | Канавка врезаниями с ломкой стружки | `x` (дно), `z` (стенка ближе к торцу), `width`, `insert_width`, `peck`, `dwell` |
| `thread` | Наружная резьба CYCLE97 | `pitch`, `x`, `z_start`, `z_end`, `depth`, `passes` |
| `drill` | Сверление по оси с выводом | `depth` (до вершины), `peck` |
| `part` | Отрезка, на последних 10 мм подача вдвое меньше | `z`, `x_end`, `slow_from` |

Скорость резания задаётся `vc` (м/мин, G96 с `lims` ≤ max_rpm) или `rpm` (G97). Для `drill` и `thread` нужны `rpm`. Привязка канавочного и отрезного резца по углу, обращённому к торцу.

Программа проверяет: заготовку против диаметра и РМЦ станка, контур против заготовки, номера инструмента против числа позиций, обороты против максимума, дно канавки против уже обточенной поверхности.

## Что проверить на станке

Сайт станка и руководство 808D не открылись при написании, поэтому:

1. **Параметры KMT-KE в `machine.py` взяты типовые** (Ø400, РМЦ 1000, 2000 об/мин, 4 позиции, точка смены X200 Z150). Сверьте с паспортом.
2. **Порядок параметров CYCLE95 и CYCLE97** взят по руководству 802D sl / 808D: `CYCLE95(NPP,MID,FALZ,FALX,FAL,FF1,FF2,FF3,VARI,DT,DAM[,_VRT])`, `CYCLE97(PIT,MPIT,SPL,FPL,DM1,DM2,APP,ROP,TDEP,FAL,IANG,NSP,NRC,NID,VARI,NUMT[,_VRT])`. Сверьте с вашей версией ПО 808D.
3. **Направление шпинделя** `M3` задано для задней резцедержки; для передней поставьте `"spindle_cw": "M4"`.
4. **Направление дуг G2/G3** зависит от того, где резцедержка; прогоните пример в симуляции стойки.
5. Первую программу запускайте в симуляции и в покадровом режиме с уменьшенной быстрой подачей.
