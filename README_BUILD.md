# Сборка установщика NEST для Windows

Выбрана связка PyInstaller `--onedir` + Inno Setup 6: на выходе один файл `NEST_Setup.exe`, а после установки — ярлык на один `NEST.exe`. Python/OCP/ReportLab на компьютере получателя не нужны. Создавать Windows EXE следует на Windows: PyInstaller не является кросс-компилятором.

1. Скопируйте **только** `build_installer.py`, `build_installer.bat`, `NEST.iss` в папку **проверенной вами настольной версии**, где есть `main.py`, `cad.py` (последняя CAD-ревизия), `nesting.py`, `pdf_report.py` (после PDF-патча). Не надо прикладывать `.venv`, `exports`, исходные STEP.
2. На машине сборки установите `C:\Python\python.exe -m pip install --user pyinstaller`. OCP и ReportLab должны быть доступны в **том же Python**: `C:\Python\python.exe -c "import OCP,reportlab; print('OK')"`.
3. Установите Inno Setup 6 на **машине сборки**. Если путь нестандартный, задайте `set INNO_ISCC=C:\путь\ISCC.exe` в текущем cmd.
4. Откройте cmd в папке проекта и запускайте именно `C:\Python\python.exe build_installer.py` (так сборка возьмёт установленный OCP). Или `build_installer.bat`, если `python` указывает на тот же интерпретатор.
5. Готовый установщик будет в `release\installer\NEST_Setup.exe`. Сборочный скрипт не меняет ваши main.py и исходные CAD-файлы; копия программы с записью в `%LOCALAPPDATA%\NEST\exports` создаётся в `release\stage`.

В установленной программе STEP и manifest сохраняются в папке пользователя `%LOCALAPPDATA%\NEST\exports\дата-время`, а PDF — в месте, выбранном при сохранении. Кнопка «Открыть папку» по-прежнему работает. Программа и её ярлыки ставятся для текущего пользователя без прав администратора. При удалении программы пользовательские результаты не удаляются.

**Важно:** скрипт проверяет импорт зависимостей, синтаксис и тесты раскладки (если `test_nesting.py` есть). Автоматически собрать и протестировать Windows EXE в среде автора нельзя. Обязательно установите NEST_Setup.exe на чистой Windows без Python, затем проверьте загрузку STEP, расчёт, STEP в КОМПАС-3D, PDF, папку вывода и удаление. Если PyInstaller не найдёт динамически импортируемый модуль OCP, пришлите полный текст ошибки: его нужно добавить в сборку.
