# NEST DESKTOP — ревизия CAD-габаритов

Это исправление для работающей настольной версии NEST_DESKTOP_rebuilt_v3. Закройте NEST. Распакуйте этот архив в папку, где находится ваш `main.py`, с заменой `cad.py` (если папка NEST_DESKTOP из архива уже существует, распакуйте рядом и подтвердите замену). Не запускайте setup.bat повторно: OCP уже установлен в C:\Python\python.exe и показал `OCP OK`. Запустите NEST через `start.bat` либо `C:\Python\python.exe main.py`.

Причина: OCP 8.0.1 возвращает из `Bnd_Box.Get()` объект Limits, который текущая Python-обвязка не переводит в Python-тип. В этой ревизии габариты читаются через `CornerMin()`/`CornerMax()` и координаты gp_Pnt; тот же метод используется при проверке STEP после экспорта. Изменения формы детали и сборки по-прежнему требуют испытаний на пользовательских файлах.

Проверка без реального CAD: `C:\Python\python.exe -m unittest test_cad_bounds.py`. Проверка файла CAD: после замены снова добавьте файл в интерфейс; в таблице должны появиться X/Y/Z. Если ошибка сохраняется, пришлите строку состояния целиком. Никаких исходных STEP эта ревизия не изменяет.
