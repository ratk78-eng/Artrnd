# NEST DESKTOP — раскладка труб по хлыстам (Windows)

Настольная программа на Tkinter: читает STEP/IGES-модели труб, раскладывает детали по хлыстам и выгружает результат в STEP (для КОМПАС-3D), CSV и PDF.

## Файлы

| Файл | Назначение |
|---|---|
| `main.py` | Окно программы |
| `nesting.py` | Алгоритм раскладки |
| `cad.py` | Работа с CAD через OCP: габариты, припуск, экспорт STEP |
| `pdf_report.py` | PDF-отчёт (ReportLab) |
| `test_*.py` | Тесты |
| `setup.bat`, `start.bat` | Установка зависимостей и запуск из исходников |
| `build_installer.py`, `build_installer.bat`, `NEST.iss` | Сборка установщика, см. `README_BUILD.md` |

Папки `exports/` и `release/` создаются программой и сборкой, в git не хранятся.

## Запуск из исходников

Нужен Python 3.11–3.14. Запустите `setup.bat`, затем `start.bat`. `setup.bat` использует первую команду `python` в PATH; для другого интерпретатора: `setup.bat "C:\путь\к\python.exe"`. Если venv/ensurepip падает, скрипт ставит OCP в профиль пользователя через существующий pip. Для PDF дополнительно: `python -m pip install --user reportlab`. Если окно не открывается, запустите `python main.py` в cmd и посмотрите ошибку.

Без OCP окно откроется, но загрузка CAD работать не будет.

## Работа

Загрузите STEP/IGES. Файлы читаются по очереди в фоновом потоке; OCP определяет длины X/Y/Z. У каждой строки своя ось длины (столбец «Ось»):
- новые файлы получают ось из списка «Ось»; «Авто» (по умолчанию) берёт наибольший габарит — у трубы это длина;
- выбор в списке «Ось» применяется к выделенным строкам, а если ничего не выделено — ко всем;
- двойной щелчок по ячейке «Ось» переключает X→Y→Z, по другим столбцам — меняет количество. «Рассчитать», затем «Создать STEP», «CSV» или «Отчёт PDF». «Пример» только для ознакомления и в STEP не экспортируется. Пороги отхода лишь помечают результат — эвристический алгоритм не гарантирует их соблюдение.

Экспорт: один хлыст → один STEP-сборка в папке `exports/YYYY-MM-DD_HH-MM-SS[_N]` (в установленной версии — `%LOCALAPPDATA%\NEST\exports`), рядом `manifest.json`. Каждая деталь поворачивается так, чтобы её ось длины шла вдоль X; первая деталь начинается в 0, следующие ставятся вдоль X, между ними рез. Припуск удлиняет копию детали вдоль её оси от единственного плоского конечного торца (на стороне «+» оси); исходный файл не меняется. При сложном торце или многотельной модели выдаётся ошибка. Единицы STEP — миллиметры; после записи файл открывается повторно и проверяются число тел и габаритная длина.

PDF содержит параметры, итоги и состав каждого хлыста; шрифт Arial/Segoe UI берётся из Windows.

## Тесты

```
python -m unittest discover -p "test_*.py"
```

Тесты `test_cad.py` строят модели в OCP и пропускаются, если OCP не установлен.
