# NEST DESKTOP — Windows без браузера

Запуск: распакуйте в отдельную папку. Запустите `setup.bat`, затем `start.bat`. Программа открывает собственное окно Tkinter. `setup.bat` использует первую команду `python` в PATH. Для другого интерпретатора откройте cmd в папке проекта и выполните `setup.bat "C:\путь\к\python.exe"`. Если venv/ensurepip падает, скрипт пробует установку OCP в профиль пользователя через существующий pip; если и pip не работает, нужно исправить установку Python. Окно может открываться без OCP, но тогда CAD-загрузка не заработает. Если GUI не открывается, запустите `python main.py` в cmd для просмотра ошибки.

Загрузите STEP/IGES. OCP определяет длины X/Y/Z; выбранная ось задаёт длину детали. Количество меняется двойным щелчком по строке. Нажмите «Рассчитать», потом «Создать STEP». Пример годится только для ознакомления и не экспортируется. CSV создаётся отдельно. Пороги отхода только помечают результат — эвристический алгоритм не гарантирует их соблюдение.

Экспорт: один хлыст → один STEP сборки в папке `exports/YYYY-MM-DD_HH-MM-SS[_N]`, кнопка открывает эту папку. Первая деталь начинается в 0, следующие ставятся последовательно вдоль X/Y/Z без поворота; рез между деталями. Припуск физически удлиняет копию от единственного плоского конечного торца; оригинал не меняется. При сложном торце или многотельной модели выдаётся ошибка, чтобы не создать неверный STEP. Для STEP предполагаются миллиметры; после записи программа повторно открывает файл и проверяет число твёрдых тел и габаритную длину.

В поставке нет исполняемого EXE: нужен Python 3.11–3.14 и OCP (`cadquery-ocp`). Стандартные тесты расчёта запускаются `python -m unittest test_nesting.py`. CAD-интеграция и КОМПАС-3D требуют проверки на вашей Windows с реальными моделями: OCP отсутствует в среде подготовки архива. Сообщайте точный текст ошибки при сбое.
